# Yashu Arora — portfolio

A static one-page site. No build step.

## Images
- `assets/profile.jpg` — headshot in the top section. Replace with a larger square photo (600 × 600 px or more) for sharper results.
- `assets/tepper.jpg` — campus photo in Education.
- `assets/projects/` — slides and screenshots used on the project pages in `projects/`.
- `assets/logos/` — company and school logos. Swap any file for an official version with the same name.

## Deploy to Vercel
Option A: push this folder to a GitHub repo, then on vercel.com choose Add New > Project, import the repo, keep Framework Preset = Other, and click Deploy.
Option B: from this folder run `npx vercel` and follow the prompts (`npx vercel --prod` for production).
